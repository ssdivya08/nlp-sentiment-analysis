# Customer Review Classification using NLP


## 📌 Project Overview
This project implements an NLP-based machine learning pipeline to classify
customer reviews into **Positive** or **Negative** sentiments using TF-IDF
and Logistic Regression.

## 🎯 Objective
- Automate sentiment classification of customer reviews
- Build an end-to-end NLP pipeline
- Achieve high classification accuracy (~92%)

## Description
This project builds an NLP-based sentiment analysis system that classifies
customer reviews into Positive or Negative categories.

## Technologies Used
- Python
- Scikit-learn
- TF-IDF
- Logistic Regression

## Accuracy
Achieved approximately 92% accuracy on test data.

## How to Run
1. Install dependencies:
   pip install -r requirements.txt
2. Run notebook:
   notebook/nlp_review_classification.ipynb
3. Or run script:
   python src/nlp_model.py
